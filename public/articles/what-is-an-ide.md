# What is an IDE?

අද මම කතාකරන්න යන්න IDE (Integrated Development Environment) එකක් කියන්නේ මොකද්ද කියලා. ඉතින් ඔයාලා IT Industry එකට එකතුවෙන්න හිතන් ඉන්නවානම් මේ වෙනකොට මේ වචනේ අහලා ඇති.

## IDE එකක් කියන්නේ මොකක්ද?

ඉතින් IDE එකක් කියලා කියන්නේ සරලවම අපි Code ලියන්න පාවිච්චි කරන software එකට. මේක නිකන්ම නිකන් software එකක් නෙවෙයි. මේකේ අපිට development කනගෙන යන්න ඔනී කරන tools බොහොමයක් ඇතුලත් කරලා තමයි තියෙන්නේ. මේ integrated කියන වචනෙන්ම එක ඇගවෙනවා.

## IDE එකක විශේෂාංග

ඉතින් අපි development එකක් කරගෙන යනකකොට ඕනි වෙන editting, compliing, running, debugging වගේ මුලික දේවල් වගේම, Git, terminal වගේ දේවලුත් මේ IDE වල ඇතුලත් වෙනවා.

ඒ වගීම ඔයාගේ project එකේ files ඔක්කොම එක තැනක තියාගෙන manage කරන වගීම, ඕනි වෙන SDK, Library වගේ දේවල් manage කරන්නත් මේ IDE ඕනි වෙනවා.

## ප්‍රධාන IDE කිහිපයක්

මේ වගේ ප්‍රධාන IDE කිහිපයක් තමයි:

1. **VS Code**
2. **IntelliJ IDEA**
3. **Eclipse**
4. **Android Studio**

තව ඕනි තරම් තියෙනවා. ඉතින් ඔයා පාවිච්චි කරන IDE එකත් comment එකක් ගෙන යන්න.
