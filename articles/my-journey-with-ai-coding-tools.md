This is the AI era. Everybody is talking about AI, GenAI, Agentic AI. But do you remember how this whole thing actually started for us, just a few years ago?

It started with a free tool called ChatGPT. Everybody tried it. In those early days, we used it like just another search engine. Whatever we asked, it had an answer. It felt magical, until we realized some of those answers weren't correct. We learned a new word for it: hallucination.

Then more LLMs showed up. Bard, Perplexity, Gemini, Claude. A huge race began, and as developers, we were right in the middle of it, using them to write code. The workflow back then: generate code from ChatGPT, copy, paste into our actual codebase, fix, repeat.

Next came tools that integrated the LLM directly into the IDE. Some were plugins, some were entirely new IDEs. One of the best, for us, was Cursor. It closed the gap: instead of copy-pasting, it generated code right where we needed it. But one thing never changed: a human still had to be in the loop, reviewing and accepting what the tool generated.

That's the shared part of the story, the one most of us in this industry lived through together. What comes next is mine.

Claude Code came along, and that's where my journey took a real turn. When it first launched, it was a command-line tool, no GUI. I was used to working visually, so honestly, I had my doubts. What pushed me to actually try it was a change in Cursor's billing policy, one that made me stop and think about what I was relying on and why.

That doubt didn't last long. Once I started working with it properly, in the terminal, something clicked. Today, I genuinely depend on Claude Code for my daily work. There's a VS Code extension too, but I still prefer the terminal. For me, it's the most amazing developer tool I've used so far.

Along the way, I picked up tips, tricks, and best practices that aren't obvious when you're starting out. So I started recording videos in Sinhala and sharing what I've learned, from the basics all the way up to subagents and Claude in Chrome, on my YouTube channel, Bulta: [Claude Code playlist](https://www.youtube.com/playlist?list=PLR6y_6k9jex06xFiQIOM07T5qhgcQy9ff).

I'd genuinely love for you to check them out and share your honest feedback.
