# What is a Library?

අද අපි බලමු මොකක්ද මේ Library එකක් කියන්නේ කියලා. සරලවම කිව්වොත් library එකක් කියන්නේ කලින්ම ලියාගත්ත code වල එකතුවක්. මොකක් හරි වැඩක් කරගන්න ඕනි වෙන tool box එකක් වගේ එකක්.

## Library එකක් පාවිච්චි කරන්නේ කොහොමද?

හිතන්නකෝ ඔයාලා project එකක් කරගෙන යනකොට database එකත් එක්ක connection එක හදාගන්න ඕනි වෙනවා. ඔන්න ඉතින් ඕකෙදි ඔයාලා connection එක open කරන්න ඕනි, query එකක් execute කරන්න ඕනි, වැඩේ ඉවර වුණාම connection එක close කරන්නත් ඕනි. 

ඉතින් කරන්න ඔයාලට ඔයාලගේම code එකක් ලියන්න පුළුවන්. හැබැයි මේ වගේ දේවල් common. ඉතින් මේකම කරන්න ඕනි වුණ වෙන කෙනෙක් ඕකටම හදපු library එකක් තියෙනවා වෙන්න පුළුවන්. ඉතින් එහෙම තියෙනවා නම් අපිට කරන්න තියෙන්නේ එක අපේ project එකට ගෙන අපේ ඉතිරි වැඩ ටික කරගෙන යන එක. එතකොට අර database connection එක manage කරන්න වෙනම code එකක් ලියන්න ඕනි නැහැ.

## Library පාවිච්චි කරන වාසි

ඒ වගේම මේකෙන් developers ලගේ කාලය ගොඩක් ඉතිරි වෙනවා වගේම, මේ වගේ library අනිවාරෙන්ම හොඳට test කරලා bugs fix කරලා තමයි තියෙන්නේ. එතකොට වාසියත් අපිට ගන්න පුළුවන්.

## ප්‍රචලිත Libraries

ඉතින් මේ වගේ libraries වලට උදාහරණ තමයි:

1. **NumPy (Python)** - ගණිත ගැටලු, number crunching
2. **React (JavaScript)** - UI & Website build කරන්න
3. **Pandas (Python)** - Data analysis, data handle කරන්න

## සාරාංශය

ඉතින් අද වෙනකොට අපි development වලදී ඕනි වෙන ගොඩක් දේවල් වලට libraries තියෙනවා. එක නිසා ඔයාලා මොකක් හරි development එකක් කරන්න ගියාම මුලින්ම බලන්න ඒ වැඩේට හදපු library එකක් තියෙනවද කියලා. එහෙම තියෙනවා නම් එක පාවිච්චි කරලා ඉතිරි වැඩ ටික කරගෙන යන එක හොඳයි.
