# What is a Framework?

Framework එකක් කියලා කියන්නේ a ready-made foundation for building software කියලා කියන්න පුළුවන්. ඉතින් ඔහොම කිව්වට ඔයා beginner කෙනෙක් නම් ඕක තේරෙන්නේ නැහැනේ. ඉතින් අද අපි බලමු මොකක්ද මේ framework එකක් කියන්නේ කියලා.

## සරල උදාහරණයකින්

ඔයාලා මොකක් හරි software එකක් ලියන්න ගත්තම හැමදේම මුල ඉඳන්ම කරගෙන යන්නත් පුළුවන්. ඒ කියන්නේ හරියට ගෙයක් හදනවා කියලා හිතන්න. ඔතන මුල ඉඳන්ම මැටි අනලා, ගඩොල් කපලා, ඕවා පුච්චලා, කැලේ ගිහින් ගස් කපලා ඇවිත් උළුවහු, පරාල, රීප්ප කපලා මුල ඉඳන්ම කරගෙන යනවා වගේ.

හැබැයි ඔහොම කරන්න ගියොත් කාලය ගොඩක් යනවා. ඒක නිසා අපිට ඕනේ දේවල් කලින් හදලා තියෙනවා. ගඩොල්, ජනෙල්, උළුවහු, වහලෙට උළු නැත්තම් sheet. ඉතින් අපිට ඕවා එකතු කරගෙන අපේ ගෙදර හදාගන්න පුළුවන්.

ඔතින් software develop කරන්න ගත්තම ඔය වගේ තමයි. හැමදේම මුල ඉඳන් හදන්නේ නැතිව කලින් හදලා තියෙන building blocks use කරලා අපේ වැඩේ කරගන්න පුළුවන්.

## Framework එකක් පාවිච්චි කරන වාසි

ඉතින් මේ වගේ framework එකක් use කරන එකේ වාසිය තමයි:

- **කාලය ඉතිරි කරගන්න පුළුවන්** - මුල ඉඳන් හැමදේම code කරන්න ඕනේ නැහැ
- **Project එක develop වෙන්නේ එක්තරා සම්මත ක්‍රමයකට** - එතකොට පසුකාලීනව maintenance කරන්න ලේසියි

## ප්‍රචලිත Frameworks

ඉතින් මේ වගේ frameworks ගොඩක් අද වෙනකොට හැම language එකටම වගේ තියෙනවා.

**උදාහරණ:**
- **Spring Boot** - Java
- **Angular** - Frontend
- **Django** - Python
- **Express** - Node.js

ඉතින් මේ එකින් එක framework එකට ඒවාට අදාළ rules, concepts තියෙනවා. ඉතින් ඒවාට අනුගත වෙලා අපිට අපේ software එක කරගන්න පුළුවන්.
